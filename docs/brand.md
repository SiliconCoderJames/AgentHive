# MiderHive 品牌规范（Brand Guidelines）

> 口号：**单体成长，蜂巢共享** / *Grow alone, thrive together.*
> 本文是所有界面、文档、物料的设计依据。改 UI 前先读这里。

## 1. 品牌隐喻

MiderHive 是「蜂巢」：每个 AI Agent 是一只独立的蜜蜂——单体时各自成长，
接入蜂巢后共享知识、技能与记忆。隐喻只出现在**营销面与氛围面**
（口号、空状态、引导页、文档标题）；**功能面永远用平实语言**
（按钮叫「注册」不叫「入巢」，列表叫「Agent 列表」不叫「蜂群」）。

## 2. 色板（默认主题「蜂巢」即品牌色板）

| 角色 | 值 | 用途 |
|---|---|---|
| 夜蓝（窗口底） | `#10141c` | 一切界面的底 |
| 深夜蓝（侧栏/状态栏） | `#0c101a` | 层级压深 |
| 卡片 | `#1a2130` | 卡片/弹层 |
| 输入面 | `#151b28` | 输入框/表格 |
| 描边 | `#2c3854` | 边框/分隔 |
| **强调蓝** | `#0ea5e9`（高亮 `#38bdf8` / 深 `#0284c7`） | 交互强调、链接、选中 |
| **蜜金（品牌色）** | `#f59e0b` | 品牌签名：logo、卡片标题、导航选中条、告警「注意」 |
| 成功绿 | `#22c55e` | 在线/成功/一切正常 |
| 阻断红 | `#ef4444` | 仅危险操作与严重告警 |
| 主文本 / 次文本 | `#e7ecf5` / `#94a3b8` | 对比度必须 ≥ 4.5:1 |

规则：
- 其余四套主题（暖沙/石墨/暗淡/经典）是**同一角色结构的换色**，角色语义不变。
- 蜜金永不用于危险/破坏性操作（红色专属）。
- 渐变只允许两处：按钮/进度条的「高亮→深」纵向渐变、品牌分隔线的「蜜金→天蓝→透明」。

## 3. 六边形母题

- 标准画法：描边宽 = 尺寸的 1/25，圆角连接（stroke-linejoin: round），
  蜜金描边、不填充；三只六边形按 logo 的共享边拼接（顶一只、下两只）。
- 出现场景：logo、空状态插画、加载/刷新指示、引导页、文档分隔符。
- 不做：单只六边形充当 logo；任意旋转；实心填充；蜂巢图案铺满背景。

## 4. 文字与语气

- 界面字体：`Segoe UI, Microsoft YaHei UI`；等宽：`Consolas`。
- 中文为主、英文为辅（i18n 双语全量）。
- 语气三原则：**平实、可执行、不卖萌**。错误信息必须带下一步动作
  （例：「请先选择一个快照」）；空状态必须带出路（例：「点击右上角＋新建…」）。
- 口号只在引导页、关于框、README、社交物料出现；不塞进按钮和表单。

## 5. Logo 与图标

- 唯一来源：`docs/assets/logo.svg`；位图/ICO 用 `python scripts/gen_icon.py`
  重生成（全出血圆角贴片、四角真透明）。禁止用无头浏览器截图 SVG。
- 蜂巢入口蓝点是 logo 的一部分，不可省略。
- 应用图标 = 深色圆角贴片 + 蜂巢；托盘/窗口/快捷方式共用同一资源。

## 6. Don't 清单

- 不引入色板之外的新蓝/新橙。
- 不把蜜蜂 emoji（🐝）当 logo 用（它只是文案点缀）。
- 不在功能按钮/表单里使用蜂巢隐喻词。
- 不加拖慢启动的启动画面（本地工具秒开本身就是体验承诺）。
- 不用红黄色系做「品牌感」装饰（红=危险、黄=注意，语义固定）。
